# GitHub Pages

Source repository: https://github.com/Aediio/nsw-election-desk

1. Push this repository to `main`.
2. Repository Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. `.github/workflows/pages.yml` tests learning/AI/refresh logic, validates source, rebuilds, validates generated output, then uploads only `dist/` and deploys it.
4. Check the Actions run and the `github-pages` deployment URL. Pull requests run validation without deploying.

The site uses relative asset paths and supports a repository subpath. No private progress or AI key is part of the deployed bundle. Only app shell, styles, runtime, approved data, D3, icons, manifest and service worker are served. README, framework and refresh tooling are source-repository files, not Pages assets.

The portable `nsw-election-learning-game/index.html` embeds everything required for core learning. Pages uses independent assets for browser caching. Both are generated by the same build. Build timestamps are deterministic from approved content or SOURCE_DATE_EPOCH; data content versions are hashes.

Offline: a successful first HTTPS visit installs a versioned service-worker cache. It never intercepts Google AI requests. Updates wait until older tabs close, preventing mixed app/data versions; reopen after deployment to adopt the update. Localhost does not register service workers, to avoid stale development assets. Install/Add to Home Screen is provided by compatible browsers. Real iOS installation and pinch testing still need a physical device.

Rollback: revert the faulty source/data commit with Git and push to main; validation and Pages redeploy the reverted version. Do not force-update historical result files as part of a current-member refresh. Users retain local progress; changed fact signatures reintroduce affected cards.

The original Mac lacks working system Git; install Apple Command Line Tools for normal command-line Git use. The repository and checkpoints created here remain valid standard Git. No build-time npm packages are required.
